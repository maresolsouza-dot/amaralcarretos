# Amaral Carretos

Página de destino das campanhas de Google Ads.

**No ar em:** https://maresolsouza-dot.github.io/amaralcarretos/

Página única, sem dependências além das fontes do Google. O conteúdo do topo
muda conforme o parâmetro da URL, para casar com o anúncio que trouxe a visita:

| URL | Serviço |
|---|---|
| `/?s=entulho` | retirada de entulho |
| `/?s=poda` | poda e retirada de galhos |
| `/?s=carreto` | carreto e frete pequeno |
| `/` | versão geral |
